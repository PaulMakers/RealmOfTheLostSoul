# AI Evidence & Screenshot Protocol

## 1. Core rule: DONE is not a claim

AI may only declare a task COMPLETE when measurable evidence exists.

Minimum evidence for visual/structural tasks:

- expected instances verified
- names verified
- dimensions/positions verified where applicable
- material/style verified
- collision/anchoring verified where applicable
- tool usage recorded where applicable
- required screenshot captured
- validation report generated

## 2. Required viewport evidence for UI

Capture and validate at:

- 1920×1080
- 1280×720
- 768×1024
- 375×812

## 3. Required map evidence

Capture:

- top-down full map
- each major district
- road intersections
- major landmarks
- terrain/Part transitions
- representative building closeups

## 4. Required UI evidence

Capture:

- Main HUD
- each major menu
- important modal/popup states
- mobile layouts
- important interaction states

## 5. Evidence record

```text
PHASE:
EXPECTED:
ACTUAL:
TOOLS_USED:
MEASUREMENTS:
SCREENSHOTS:
FAILURES:
REPAIRS:
STATUS:
```

A screenshot is evidence only when it is tied to a requirement and validation result; it is not a decorative attachment.
